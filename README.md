# S8mini 产品人群深层洞察与内容增长系统

中文本地工作台。用 React、TypeScript、Vite 和 Tailwind 构建，支持桌面和移动端。默认使用规则生成脚本，无需 API 密钥。

## 启动

建议使用 Node.js 24。以下命令可使用 npm，也可用 pnpm 执行同名脚本。

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

启动后打开 [本机预览](http://127.0.0.1:5173/)。浏览器按地址分别保存数据。日常使用时请保持主机名和端口一致。

```sh
npm run check
npm test
npm run build
npm run preview
```

当前 Codex 工作区已安装依赖。若本机终端找不到 Node 或 npm，可在工作区根目录使用 Codex 自带的运行环境。

```sh
export PATH="$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/fallback:$PATH"
pnpm dev --host 127.0.0.1 --port 5173
```

生产页面位于 `dist/client/`，Sites 服务端入口位于 `dist/server/index.js`。如使用 pnpm，可用 `pnpm install --frozen-lockfile` 安装锁定版本。

## 使用流程

1. **人群洞察库**。打开内置的「家庭青年 × 旅行家用」或「都市白领女性 × 早起通勤」，查看关系、决策角色、场景和反证。在「人群 × 业务需求」中分别多选，系统自动预览所有交叉组合；保存后生成可编辑的待验证洞察卡，已有相同组合会跳过。示例为待验证假设，置信度 D。A 表示多来源直接证据，B 表示单一直接证据，C 表示间接线索。
2. **产品事实库**。295g、11 万转马达、2 亿级负离子、57℃ 智能恒温与权益均为待核验输入。用可回查的原件补充出处、适用条件和日期，再设置为已核验。
3. **洞察匹配矩阵**。把一张洞察、具体痛点、卖点和一项产品事实关联起来，并注明证据位置或采集计划。
4. **文案库**。先选包含实际吹发痛点的人群洞察，再从爆款策略实验室选结构。模型先生成可编辑策划，然后按确认的结构写一份分镜。仅有竞品报告参考时，脚本标为待验证试拍稿。脚本版本保存策划和结构来源，可继续逐镜编辑、审核和导出。
5. **合规审核**。从已保存版本加载，或输入画面、字幕和口播，查看规则命中及建议措辞。审核记录保留输入与关联版本，风险计数按当前事实库重新计算。正式发布仍需人工复核平台要求和证据。
6. **实验复盘**。填写真实报表、口径和统计区间，关联洞察、脚本及版本。5 秒完播率 = 完播 ÷ 展现，CTR = 点击 ÷ 展现，点击转化率 = 成交 ÷ 点击，净 ROI =（成交金额 − 退款金额）÷ 花费。零分母显示空值。退款调整后毛利估算为录入毛利减退款，扣除投放费得到贡献估算。请填写退款前毛利，估算未计退货回收与其他费用。默认 15% / 5% / 10% / 3.5 和 1,000 次展现为可编辑的内部待校准参考值。
7. **反馈回流**。记录实验对假设的支持或否定及其理由。洞察卡显示实验结论，编辑页可追溯来源和反证。实验结论有分歧时会显示分歧，洞察的综合状态和置信度由操作者评估。
8. **数据与设置**。完整备份可使用 JSON 或 UTF-8 CSV。CSV 列为 `collection,id,data`，其中 `data` 是 JSON 对象。建议先导出一份查看结构。导入经字段和关联校验后替换当前数据。数据保存在当前浏览器，同事协作或换设备时用备份迁移。

## 本地视频拆解与素材管理

在「脚本工作台 → 视频素材与拆解」选择素材类型与本地视频，然后点击「自动拆解并存入管理」。系统按实际时长采样画面变化并保存关键帧；0–3 秒、3–8 秒仅作参考，不是固定切点。视频和报告通过 IndexedDB 保存在当前浏览器。素材管理可回看原片、点击镜头时间码定位、替换带时间码的字幕、导出 JSON 报告和删除素材。

可导入 SRT 或 VTT 作为口播证据，也可启用本地中文识别。识别首次从模型仓库下载 Whisper Tiny 模型，音轨在浏览器计算，不上传视频。模型不可下载、编码不兼容或视频超过 10 分钟时，可用字幕补齐口播。关键帧检测基于像素变化，可能漏掉快切或把大幅运动当成切点；画面语义、转写和规则推断需对照原片校验。

单条报告包含逐镜表、开场至行动引导的内容线索、六层深挖。达人素材另有八项检查。在「带货 8 维对标诊断」选择一条参考素材和一条达人素材，按证据对照并给出复核方向。参考拆解结构按任务明确给出的流程实现，页面保留抖音大盘分析文档目录链接。原视频不进入工作区 JSON/CSV 备份。

## 站点 AI 生成

文案库通过同站点的 `/api/gpt-script` 请求策划与正文。Sites 服务端配置 Secret `DEEPSEEK_API_KEY` 后使用 DeepSeek，默认模型 `deepseek-flash`，可用 `S8MINI_DEEPSEEK_MODEL` 指定。尚未配置 DeepSeek 时使用已配置的 Secret `OPENAI_API_KEY`。`S8MINI_GPT_ACCESS_MODE=public` 允许访客免登录使用站点模型；`authenticated` 允许所有已登录的 ChatGPT 账号调用。也可通过 `S8MINI_GPT_ALLOWED_EMAILS` 将调用范围限定为特定账号，此时移除访问模式变量。OpenAI 默认模型为 `gpt-4.1-mini`，可用 `S8MINI_GPT_MODEL` 指定。

用户点击生成时，服务端只接收本次选择的人群洞察、结构来源、匹配的已核验事实，以及写稿时已经编辑的策划。API 超时或未连接时可继续手动编辑策划。旧的 Vite 自定义代理入口仍用于实验复盘的规律建议。

## 源码结构

- `src/main.tsx`　导航、工作区状态和保存入口
- `src/domain.ts`　数据模型、示例、脚本生成、合规规则、实验公式
- `src/storage.ts`　localStorage、备份编解码和导入校验
- `src/dashboard.tsx`、`src/library.tsx`　仪表盘、两类资料库和匹配矩阵
- `src/scripts.tsx`、`src/operations.tsx`　脚本、合规、实验和设置
- `src/script-planning.ts`　人群与投放结构匹配、策划和分镜验证
- `server/gpt-script.mjs`　Sites AI 生成接口、访问校验和服务端模型调用
- `src/ui.tsx`、`src/style.css`　通用界面组件与响应式样式
- `tests/core.test.ts`　事实引用、规则审核、指标和备份回归测试

首版为单浏览器工作区。规则审核依赖词库与已录入的证据，改写后的营销说法仍可能漏检。系统未预置用户样本、实验结果或研究结论。

### 视频证据、规律与设计闭环

脚本工作台内的「视频素材与拆解」支持保存平台来源、HTTPS 视频直链与本机文件。平台分享页需要在原平台回看。已有帧差候选段可转入人工复核，也可直接新增带时间码的开场、承接段和其他镜头。把实际画面、口播、字幕、推断、证据及局限分开记录。

从带证据的段落提炼候选规律，人工补齐依据与迁移建议后审核。规律可并入同类案例的证据快照；「交叉支持」至少要求两条独立素材，「实测验证」需要关联有来源的实验记录，操作者仍须核对实验设计和因果局限。素材删除后已保存的证据快照仍可查。

设计库用已审核规律、真实洞察和已核验产品措辞生成三个可编辑开场，共用后三秒以后的测试脚本。送入脚本工作台并保存版本后，现有实验复盘可关联该版本，实验记录会回流规律卡。模板按 15、30、45 秒分配镜头，实际配音时长需试读。视觉语义由人工校对，口播模型可用性取决于浏览器和首次下载。

工作区 JSON/CSV 备份包含规律、设计及脚本关联。原视频与关键帧仍在 IndexedDB，单条拆解报告可另外导出。

创作记忆在浏览器工作区按当前人群洞察检索已审核规律、近期保存脚本和有出处的版本投放记录。可在策划区查看或关闭发送。保存 AI 稿件时，模型信息与写稿时的记忆摘要随版本保留，并进入 JSON／CSV 备份。工作区数据按浏览器存储。
